# 🐍 Flask Snake AI

Interactive Snake game built with Flask and JavaScript.

Play manually or watch an AI learn to play using reinforcement learning with TensorFlow.js.

## Features

- **Manual Controls:** WASD, arrow keys, mobile-friendly on-screen controls.
- **AI Mode:** Neural network takes control; trial-and-error learning.
- **Score Tracking:** Displays current and session best score.
- **Game Controls:** Start, restart, pause, and resume.

---

## Technologies

| Component | Technology |
|-----------|------------|
| **Frontend** | HTML, CSS, JavaScript |
| **Backend** | Python, Flask |
| **Neural Network** | TensorFlow.js |

---

## Run Locally

1. `pip install -r requirements.txt`
2. `python app.py`
